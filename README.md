# Notice Board Application

## Description
A Notice Board application built using Next.js, Prisma, and PostgreSQL. Users can create, view, edit, and delete notices.

## Tech Stack
- Next.js (Pages Router)
- Prisma ORM
- PostgreSQL
- React

- ## How to run the project locally
Before running the project, make sure you have:
- Node.js installed
- PostgreSQL installed and running
- npm installed
- Then :
  # Generate Prisma Client
- npx prisma generate
  # Push Database Schema
- npx prisma db push
 # Start the Development Server
- npm run dev

# The application will be available at:
- http://localhost:3000

- ## One thing you would improve with more time
- If I had more time, I would enhance the notice creation feature by allowing users to upload images directly from their device instead of providing image URLs manually. This would improve the user experience and make the application more convenient and user-friendly. The images could be stored using a cloud storage service such as Cloudinary or AWS S3 and linked to the notices automatically.
